# Ясно

Учебный тренажёр для школьников 5–6 класса.

Сайт: https://quest-znaniy-glass.vercel.app/

Полные исходники, API, миграция Supabase и тесты находятся в yasno-source.zip. Распакуйте архив, выполните pnpm install и pnpm run build. Локальный запуск: node scripts/dev.cjs. Тесты: node --test tests/*.test.cjs.

Статус проверки и ограничения: AUDIT.md.
